# YANASUSHI Delivery

Сайт доставки суши: отдельные страницы каталога, общая корзина, промо-слайдер и отзывы с фото и панель управления меню, слайдами и отзывами.

## Локальный запуск

```sh
npm ci
npm run build
npm start
```

Node.js 24 и Python 3. Откройте порт 8000. Готовые HTML/JS-файлы также входят в репозиторий. Карточки каталога видны без JavaScript; для корзины нужен JavaScript.

## Страницы

- `index.html` — главная и предложения.
- `sushi.html`, `sets.html`, `promo.html`, `extras.html` — меню.
- `contacts.html` — контакты и доставка.
- `reviews.html` — отзывы гостей, 1–5 звёзд и фото.
- `admin.html` — управление меню и баннерами главной.

## Публикация

Workflow `.github/workflows/pages.yml` собирает и публикует сайт при каждом push в `main`. В Settings → Pages нужно выбрать Source: **GitHub Actions**.

Адрес после первой успешной публикации: https://eterna1g.github.io/yanasushi/

`npm run export` создаёт `dist/` только с публичными файлами сайта. Исходники Worker, тесты и служебные файлы туда не входят.

## Telegram и админ-панель

API заказов: https://yellow-term-d7c1.zubashenkoserhii.workers.dev

Адрес задан в `ORDER_API_URL` файла `site-settings.js` и используется витриной и админ-панелью. Telegram-токен хранится только в секретах Cloudflare Worker. Публикация сайта не изменяет Worker и не отправляет тестовые заказы.

Существующий Worker может принимать заказы без поддержки каталога: в таком случае сайт показывает встроенные 17 позиций. Для публикации меню из админ-панели нужны API `/catalog` и `/slides`, KV-привязка `CATALOG` и секрет `ADMIN_TOKEN` — см. [ADMIN_SETUP.md](ADMIN_SETUP.md).

Origin для CORS: `https://eterna1g.github.io`, без пути репозитория.

Контактные ссылки, номер телефона, адрес и условия доставки задаются в `site-settings.js`. Реальные контактные данные пока не заполнены.

## Проверки

```sh
npm test
npm run test:browser
```

Для браузерных проверок нужен Chromium: `npx playwright install chromium` или установленный системный браузер. Тесты не отправляют сообщения в Telegram.

Источники фотографий: [assets/PHOTO_SOURCES.md](assets/PHOTO_SOURCES.md).

Главная содержит шесть баннеров с интервалом 4,5 секунды. В админке раздел «Слайды» позволяет менять тексты RU/UA, фото, ссылки, порядок, видимость и интервал (3–15 секунд). Черновики меню и слайдов сохраняются отдельно. Общая публикация слайдов требует обновлённого `cloudflare-worker.js`; используется существующая привязка CATALOG (отдельный ключ `slides`) и тот же ADMIN_TOKEN. Без нового API сайт показывает встроенные баннеры.

## Отзывы, антиспам и проверка цен

Новая версия требует Worker API v2 и привязку Durable Object `PUBLIC_DATA`. Перед публикацией интерфейса установите Worker по [REVIEWS_SECURITY_SETUP.md](REVIEWS_SECURITY_SETUP.md): там описаны сохранение действующего CATALOG, установка через Wrangler и временное окно совместимости старой корзины. Новая серверная часть проверяет цены и доставку, блокирует повторные заказы, ограничивает частоту отправок и хранит отзывы с фото. В админке можно удалять отзывы и фотографии.
