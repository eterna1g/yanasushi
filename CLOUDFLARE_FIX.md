# Исправление публикации меню

На действующем Worker обнаружена старая версия: `GET /catalog` возвращает 405, а OPTIONS разрешает только POST и Content-Type. Браузер не может отправить PUT с Authorization и показывает Failed to fetch. Сам ключ администратора на этом этапе ещё не проверяется.

## Обновить существующий Worker

1. Откройте Cloudflare → Workers & Pages → **yellow-term-d7c1** → **Edit code**.
2. Замените код главного модуля полным содержимым [cloudflare-worker.js](cloudflare-worker.js), сохраните и нажмите **Deploy**. Это готовый файл без импортов. `worker.js` — исходник для Wrangler, он импортирует отдельный каталог и не подходит для вставки одним файлом.
3. В **Bindings** подключите KV namespace с именем привязки **CATALOG**. Если такая привязка уже есть, сохраните её и используйте прежнее хранилище. Если хранилища нет — создайте namespace и подключите его как CATALOG.
4. В **Variables and Secrets** проверьте секрет **ADMIN_TOKEN** (от 24 символов) и переменную **ALLOWED_ORIGIN** = `https://eterna1g.github.io` (без `/yanasushi/`). Секреты **TELEGRAM_BOT_TOKEN** и **TELEGRAM_CHAT_ID** сохраните без изменений. Используйте настройки Production, а не только Preview.
5. Откройте https://yellow-term-d7c1.zubashenkoserhii.workers.dev/health — ожидается JSON с `ok: true`, `apiVersion: 1`, `catalogStorage: true`, `adminConfigured: true`. Значения секретов этот маршрут не возвращает.
6. В админ-панели нажмите «Опубликовать меню». Изменения KV могут распространяться до минуты. При отсутствии хранилища или ключа новая панель показывает конкретную причину.

Обновление GitHub Pages публикует интерфейс сайта; код Worker на Cloudflare нужно обновить отдельно. Полномочия ADMIN_TOKEN предназначены для редактирования меню, а не для обновления кода Worker через API Cloudflare.

## Что проверено

- На действующем опубликованном Worker — безопасные GET и OPTIONS; подтверждены 405 и старый CORS. Реальные заказы не отправлялись, существующее меню не перезаписывалось.
- Исправленный Worker — в workerd/Miniflare с настоящим KV и браузерными HTTP-запросами между разными портами: OPTIONS/CORS, авторизация, сохранение, чтение, фото, редактирование и удаление.
- Панель — автосохранение и восстановление черновика, поиск RU/UA, импорт/экспорт, некорректный ключ, старый Worker, мобильная ширина.
- Корзина — пересчёт суммы и доставки, переходы между страницами, неуспешная отправка с сохранением корзины, повтор и успешный ответ. Внешний Telegram в этих проверках заменён тестовым транспортом: ни одно сообщение в реальный чат не отправлено.
- Все страницы, слайдер и статический каталог без JavaScript остаются в автоматических проверках.

Команды: `npm test`, `npm run test:browser`. Для отдельной полной проверки панели и Worker: `npm run test:admin`.

## Публикация слайдов

Редактор баннеров требует актуального `cloudflare-worker.js` из этого репозитория: он добавляет `/slides` рядом с `/catalog`. Если меню уже публикуется, но слайды — нет, замените только код Worker и нажмите Deploy. Существующие CATALOG и секреты сохраняются, данные меню остаются под ключом `menu`, слайды записываются отдельно под ключом `slides`. После Deploy в админке → «Слайды» нажмите «Загрузить с сайта» или опубликуйте сохранённый черновик.
