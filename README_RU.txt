YANASUSHI — автоматическая отправка заказов в Telegram

Содержимое:
- index.html — сайт, изменённый для автоматической отправки после оформления заказа.
- worker.js — Cloudflare Worker, который пересылает заказ в Telegram.
- wrangler.toml — минимальная конфигурация Worker.

1. Создайте Telegram-бота через @BotFather и скопируйте токен.
2. Создайте/откройте Cloudflare аккаунт → Workers & Pages → Create → Worker.
   Вставьте содержимое worker.js в редактор и Deploy.
3. В настройках Worker → Settings → Variables and Secrets добавьте СЕКРЕТЫ:
   TELEGRAM_BOT_TOKEN = токен от BotFather
   TELEGRAM_CHAT_ID = ID чата, куда слать заказы
   Не вставляйте токен в index.html и не отправляйте его кому-либо.
4. Узнайте TELEGRAM_CHAT_ID:
   - Напишите своему боту /start (или добавьте бота в нужную группу).
   - Откройте https://api.telegram.org/botВАШ_ТОКЕН/getUpdates и найдите message.chat.id.
   - Если используете группу, добавьте туда бота и отправьте сообщение в группу.
   После получения ID не публикуйте URL с токеном.
5. (Рекомендуется) В Worker добавьте переменную ALLOWED_ORIGIN со значением точного origin сайта,
   например https://имя-сайта.netlify.app — без завершающего слеша.
6. Скопируйте публичный URL Worker, например https://yanasushi-orders.<ваш-поддомен>.workers.dev.
   Откройте index.html и замените YOUR-WORKER-NAME.YOUR-SUBDOMAIN на реальный адрес Worker
   в строке ORDER_API_URL. Загрузите обновлённый index.html на Netlify или GitHub Pages.
   Сайт и Worker должны быть опубликованы; открытие HTML локально не отправит заказ надёжно.
7. Проверьте заказ тестовыми данными и убедитесь, что сообщение пришло в правильный чат.

Важно:
- Токен бота хранится только в Cloudflare Worker Secrets.
- Telegram ID получателя задаётся на стороне Worker.
- Сейчас сайт отправляет текст, сформированный на клиенте. Для реального магазина желательно
  дополнительно добавить серверную проверку цен/состава заказа, антиспам и журнал заказов.
- Если отправка не удалась, клиент увидит ошибку и сможет повторить отправку.
