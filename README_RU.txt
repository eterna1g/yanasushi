YANASUSHI — сайт и панель управления меню

Готовые страницы:
- index.html — главная, категории и популярные блюда.
- sushi.html — суши: 6 роллов и 4 нигири.
- sets.html — 3 сета.
- promo.html — 5 акционных позиций.
- extras.html — 4 дополнения: суп, напиток и соусы.
- contacts.html — контакты и доставка.
- admin.html — управление каталогом.

Каталог встроен в HTML и виден даже без JavaScript или при недоступном API.
Для общей корзины между страницами и работы с API запускайте сайт через
HTTP-сервер из папки проекта:
  python3 -m http.server 8000

При загрузке на GitHub Pages загрузите все HTML-страницы, styles.css,
app.bundle.js, admin.css, admin.bundle.js и папку assets целиком.
Загрузка одного index.html недостаточна. Сборки уже включены в архив.

Разработка (Node.js 20+):
  npm ci
  npm run build
  npm test
  npm run test:browser

Шаблоны страниц: templates/. Исходники: app.js, admin.js, catalog.js,
menu-view.js, locales.js, motion.js. После изменений выполните npm run build.
Общая логика карточек используется и при сборке HTML, и в браузере.
Верхняя панель и реальные контакты настраиваются в site-settings.js.
Слайдер: carousel.js и promotions.js; картинки — assets/banners/.
Он переключается каждые 6 секунд; поддерживает стрелки, точки, свайп,
клавиатуру и паузу, учитывает уменьшение движения.
Цены на баннерах берутся из каталога. Новые изображения созданы для сайта.

Для сохранения общего каталога через админ-панель нужен Cloudflare Worker
с KV-привязкой CATALOG и секретом ADMIN_TOKEN. До подключения можно
редактировать и экспортировать черновик; он также автоматически сохраняется
в браузере без ключа администратора. Подробности: ADMIN_SETUP.md.
Ключ администратора и токен Telegram не храните в HTML или Git.

Фотографии локальные, иллюстративные; источники: assets/PHOTO_SOURCES.md.
Реальные заказы и публикация на GitHub Pages автоматически не выполнялись.
